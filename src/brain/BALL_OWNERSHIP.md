## 保留的约束

仍由最小在线球员号协调、多数确认球权，一次只授权一台。交接保留旧 SDK 退出等待，失去多数时不会自行抢球。共享球用于接近、找球和申请球权，SDK 启动仍需要有效本机球源。

让行速度上限 0.4 m/s，应用原有多队友避碰和场地边界；没有可行出口时停止。让行不覆盖 INITIAL、READY、SET、停止比赛、罚时、点球和任意球动作。定位或球检测失效仍可能阻止清球，新增日志用来区分原因。

没有整体复制原 Demo：对照目录的前锋近球分支允许绕过主控判断，整体恢复会失去单一主攻约束。先修正“有球权却被队友封住”的行为，场上效果还需验证。

| 日志 | 排查含义 |
| --- | --- |
| `phase=ready owner=N lead=1` | 已获得球权，继续检查踢球入口 |
| `phase=no_quorum` | 在线且符合定位、上场条件的确认者不足 |
| `phase=handoff` / `awaiting_echo` | 等待旧主控退出或队友确认；短暂出现正常 |
| `phase=no_candidate` / `ineligible` | 查看 `control`、`role`、球源、球距、场地坐标和 `goalie_claim` |
| `kick_space_blocked=1` | 队友仍占用脚边或清球通道，查看非主控的 `[Yield]` |
| `[Yield] vx=0 vy=0` | 可能已让开并站定，也可能没有安全出口，结合位置判断 |
